# 导师反馈后的项目范围调整

日期：2026-11-10。依据：导师认为四轮结构对整体项目帮助不大；作者决定在物理模型中保留四轮，在代码中舍弃四轮。

## 已确定的边界

| 部分 | 本轮安排 |
| --- | --- |
| 实体身体 | 保留四个轮子、底盘、轮架及既有 CAD 结构；不要求重新建模 |
| 轮子角色 | 身体造型、底部支撑与机械制作痕迹；不以自主行走作为作品功能 |
| 软件 | 移除轮电机控制、驱动板初始化、编码器读取、CPR/转速计算和底盘零速模块 |
| 研究动作 | 保留水平/俯仰头部动作，重点使用有界水平转向及停顿、语音编排 |
| 研究问题 | 延续《轮到谁？》：同一种头部转向如何被理解为确认、邀请或轮次分配，人怎样协商 |
| 评价 | 关注回应、理解、协商和修复；不再安排行驶、轮速、里程计、避障或导航性能评价 |
| 供电 | 延续无电池拖线；轮电机不接入本轮动力系统，头部与计算/感知供电保留并另行实测 |

这项决定是研究范围收敛，不是声称四轮在所有机器人项目中都没有价值。当前实验已经围绕头部转向展开，将移动底盘作为独立开发任务不会直接验证现有研究问题，因此从本轮软件和验收任务中移除。

不把“保留轮子”当作额外互动能力，也不预先声称观众会怎样理解这些轮子。若轮子使观众产生移动预期，可作为现场观察记录，不据此增加移动功能或当作已验证结论。

## 论文与汇报表述

可使用：

> 本作品保留四轮机器人身体，但将其作为静态实体结构。软件与交互研究集中于头部转向、停顿和语音编排，探索人在多人场景中如何理解与协商机器人的注意和互动轮次。底盘移动不纳入本轮实现与研究评价。

机械贡献仍可讨论身体比例、装配、结构约束与头部运动。项目贡献应落在这些物理制作如何支撑互动编排，以及参与者如何理解和回应；不以未实现的行走或导航作为贡献。

WT-02 的双策略安排、确认与邀请的区分、参与者研究规则保持原有研究逻辑。视觉只作为已规定的观察辅助，不因本轮收敛而升级为身份识别或自动轮次判断。
