# 四轮软件移除与验证记录

2026-11-10。范围：实体保留四轮，当前软件只保留头部执行相关控制；未修改 CAD 或访问真实硬件。

## 代码变更

- Arduino 改为 head-1：删除轮速数组、驱动板 I²C 初始化/寄存器写入、编码器反馈、CPR 与转速换算、drive 模式及轮速动作租约。
- 保留 USB、双舵机 D10/D11、供电/限位验收门槛、session/序号/epoch、200 ms 心跳、USB 断连、故障锁存与 WDT。
- prepare 不输出 PWM；servo 才开始发送脉宽；stop、断连、超时和故障关闭 PWM，不宣称已断电或机械到位。
- 主机控制台删除 move、zero、enc 与 drive，移除 CPR 工具及其旧测试。旧指令在生产协议解析层被拒绝。
- 统一程序移除 StationaryChassis、chassis_policy 与 chassis/wheels_rpm 状态，schema 升为 2、版本 v0.2.2；保留感知、虚拟头部、文本和状态页。
- 《轮到谁？》适配器要求 head-1，拒绝旧四轮固件和已经活动的会话；研究状态机、动作编排和语音路径保留，版本 v0.1.1。
- 软件验收不再运行旧四轮接线静态测试；历史电路生成器与四轮设计文件保留为历史。当前实物验收表以头部系统为范围。
