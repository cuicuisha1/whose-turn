# 本轮硬件使用边界：四轮仅保留结构

2026-11-10。实体模型保留四轮，软件只控制头部。本文是现有方案的范围变更说明，不是重新完成电气验证的施工图。

| 支路/组件 | 本轮安排 |
| --- | --- |
| 四轮、轮架和底盘 | 保留实体与 CAD；展示/研究时固定或制动，保证头部运动时稳定 |
| 已购 TT 电机 | 可保留机械装配；动力线断开，不作为动作执行器 |
| DRV8833、原编码器电机板 | 不接入当前控制与动力系统；不再要求固件适配 |
| 轮电机专用降压和动力支路 | 不作为本轮运行需求；旧电路图中的此支路不继续接通 |
| Arduino Uno R4 WiFi | USB 通信与供电，D10/D11 控制双舵机；其余引脚不用于轮控 |
| 头部、云台和双舵机 | 保留；沿用外部舵机稳压支路与共地，实际电压/电流/限位另行验收 |
| Jetson、相机、麦克风、音箱及显示 | 保留现有项目角色；不据此宣称新增语音/视觉能力已接通 |
| 供电 | 延续无电池拖线；按实际接入负载复核电源、保险、USB回灌、接地与开关 |

当前固件不会向任何轮驱动板写“零速”或发关闭指令。若旧驱动板仍通电，不能依赖更新固件让它停止；先断开轮动力，再进行头部测试。保留实体轮子不要求保留其驱动电源。

舵机停 PWM 与关闭物理电源不同；支撑好头部并保留物理切电方式。删除轮驱动后，不直接沿用过去按整车负载设定的保险值，也不在没有测量的情况下改写新的保险值。

11 月 8 日 TT 四轮拖线 PDF/CSV、旧 N20 方案、v0.8.1 电池版和 hardware 生成器保留为历史设计，不是本轮整机完整接线依据。本轮没有更改 CAD 或重新导出 PDF。当前运行所需信号与检查表见 [头部固件说明](../project%20code/firmware/README.md) 与 [实物验收表](../project%20code/firmware/commissioning.csv)。
